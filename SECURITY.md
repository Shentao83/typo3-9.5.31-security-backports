# Security

This community repository covers the listed changes for the classic TYPO3 9.5.31 release. It does not provide ongoing support for TYPO3 9 or coverage for unrelated vulnerabilities. Follow [TYPO3 Security Advisories](https://news.typo3.com/security/) for official notices and use a supported TYPO3 version when possible.

If you find a security problem in these backports, report it through this repository's private vulnerability reporting feature when available. For a vulnerability in current TYPO3 Core, contact the TYPO3 Security Team. Keep sensitive information such as credentials, real site data, private configuration and request logs out of public issues.
